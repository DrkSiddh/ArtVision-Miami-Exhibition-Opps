# ArtVision Miami Exhibition Opportunities

Running database and narrative scripts for free (and select prestigious low-fee) opportunities to exhibit digital or physical art during Miami Art Week 2026, with emphasis on web3/crypto-related organizations and curators.

## Files
- `narrative_script.md`: Conversational podcast segment script (friend over coffee style) for ArtVision brand.
- `opportunities_database.md`: Searchable Markdown database of opportunities with deadlines, keywords (e.g. MIAMI), URLs, application details (questions, receipts/materials), fees (with justification if any), event dates, and status.

## Usage
Search the database for keywords like **MIAMI** to find still-open calls. Each day, highlight 1-3 new or active opportunities before their deadlines expire.

Voice: Encouraging, uplifting, never punching down.

Miami Art Week 2026 runs approximately November 30 – December 6, 2026.

Last updated: November 7, 2026.
